# YouTube Auto — AI/Tech News Video Pipeline

## Project Overview
Automated pipeline that fetches today's trending AI/tech topic (via Google Trends) and generates a Fireship-style YouTube video (~5 minutes). Uses Cartesia Sonic TTS (primary) with Kokoro fallback (voice: am_adam, speed 1.15) for narration, Pillow for dark-themed visual frames with real web images, MoviePy for video assembly. Script is generated by Claude Code Sonnet 4.6 subagent, not hardcoded. Agent teams orchestrate the pipeline.

## Niche
AI and tech news — new model releases, feature drops, tool launches, industry shifts. Think: "Claude just dropped /dream", "GPT-5 benchmarks leaked", "Google kills another product". Fast-moving, opinionated coverage.

## Target Style
Fireship's information density + AI Explained's depth + a distinct personality that takes positions. NOT a press release reader. NOT a Wikipedia summary. A creator who happens to use automation.

# ANTI-AI-SLOP GUIDELINES

These rules are MANDATORY for every script, narration, and visual generated by this pipeline. Violating these makes the content detectable as AI-generated, which leads to demonetization, algorithmic suppression, and viewer abandonment.

---

## 1. BANNED PHRASES — HARD BLOCK LIST

These words/phrases MUST NEVER appear in any script or narration. They are the #1 signal of AI-generated text. If you catch yourself writing any of these, rewrite the entire sentence.

### Tier 1: Instant AI Detection (never use under any circumstance)
- "delve" / "delving"
- "dive into" / "deep dive"
- "unpack" / "let's unpack"
- "in today's rapidly evolving landscape"
- "in the ever-evolving landscape"
- "in today's fast-paced world"
- "game-changer" / "game-changing"
- "revolutionize" / "revolutionary"
- "realm"
- "tapestry"
- "testament"
- "nuance" / "nuanced"
- "landscape" (when used metaphorically)
- "paradigm" / "paradigm shift"
- "leverage" (as a verb meaning "use")
- "utilize" (just say "use")
- "facilitate"
- "foster"
- "synergy"
- "holistic"
- "robust"
- "seamless" / "seamlessly"
- "cutting-edge"
- "groundbreaking"
- "transformative"
- "pivotal"
- "multifaceted"
- "comprehensive"
- "it's important to note that"
- "it's worth mentioning that"
- "at the end of the day"
- "moving forward"
- "in terms of"
- "when it comes to"
- "navigate" (metaphorical — "navigate the challenges")
- "embark on a journey"
- "shed light on"
- "pave the way"

### Tier 2: Overused AI Structures (avoid — rewrite if found)
- "Whether you're a [X] or a [Y]..."
- "Not only...but also..."
- "On the one hand...on the other hand..."
- "From [X] to [Y], [Z] is..."
- "In conclusion..." / "To sum up..." / "In summary..."
- "Without further ado..."
- Starting sentences with "Importantly," / "Notably," / "Interestingly,"
- "Let's explore..." / "Let's take a look at..."
- "First and foremost"
- "Last but not least"
- Three-item lists where each item is the same length (vary your rhythm)

### What to Use Instead
- Short, punchy words: "use" not "utilize", "help" not "facilitate", "big" not "comprehensive"
- Colloquial language: "this is wild", "okay so here's the deal", "honestly?", "look,"
- Specific language: instead of "game-changer", say exactly what changed and why it matters
- Numbers and specifics: instead of "significant improvement", say "40% faster" or "cuts cost by half"

## 2. SCRIPT STRUCTURE RULES

### Opening (First 5 Seconds) — THE HOOK
The first line of every video MUST grab attention. No generic intros. No "hey guys welcome back".

**Good hooks:**
- Start with the news: "OpenAI just killed Sora." (punchy, no filler — don't pad with "not paused, not pivoted, killed")
- Start with a question: "Why would a company shut down a product 50 million people used?"
- Start with a contrarian take: "Everyone's saying this is bad for OpenAI. I think it's genius."
- Start with stakes: "If you're building anything with AI video right now, you need to hear this."

**Bad hooks (NEVER use):**
- "Hey everyone, welcome back to the channel"
- "In today's video, we're going to talk about..."
- "So, a lot has happened in the AI world this week"
- "Before we get started, make sure to..."
- Any variation of "let's dive in"

### Body Structure — BREAK THE FORMULA
Do NOT follow the same structure every video. Rotate between these patterns:

**Pattern A: Story Arc**
Hook → What happened → Why it matters → Who wins/loses → Hot take → What's next

**Pattern B: Contrarian**
Hook → Common narrative → Why it's wrong → The real story → Evidence → Prediction

**Pattern C: Comparison**
Hook → The announcement → vs. what existed before → vs. competitors → Who should care → Verdict

**Pattern D: Timeline**
Hook → Where we were 6 months ago → What just changed → Immediate impact → 6-month prediction

Pick randomly. Never use the same pattern twice in a row.

### Closing — EARN THE ENGAGEMENT
- End with a genuine prediction or opinion that could be wrong
- Ask a real question that invites debate: "Do you think Google actually ships this, or is it another demo that disappears?"
- NEVER say "like and subscribe" or "hit the bell" or "let me know in the comments"
- NEVER say "thanks for watching" — end on the content, not meta-commentary

### Pacing Rules
- No more than 3 sentences at the same energy level in a row
- After every 60-90 seconds of narration, shift something: tone, topic angle, or visual
- Use short sentences for impact. Then follow with a longer one that explains the context behind the short punchy statement you just made.
- Rhetorical questions break monotony — use 2-3 per video, not more
- Pause markers ("...") before key reveals or after surprising statements

### Topic Transitions — "Speaking of X" Bridges
NEVER hard-cut between topics. Find a word or concept in topic 1 that relates to topic 2 and use it as a natural bridge.

**Good transitions:**
- "...and that's the third major partnership OpenAI lost this quarter. Speaking of companies making questionable decisions..."
- "...which brings us to the part nobody expected."
- "Now, if you think that's wild, wait until you hear what Google did."

**Bad transitions (NEVER use):**
- Hard cut with no connection between topics
- "Moving on to our next topic..."
- "In other news..."
- "Now let's talk about..."

### Anti-Filler Rule — NO SYNONYM PADDING
Never pad a statement with synonyms for emphasis. Say it once, say it strong.

**BAD:** "Not paused. Not pivoted. Not shelved. Killed." (AI filler — sounds robotic)
**GOOD:** "OpenAI just killed Sora." (punchy, direct, human)

**BAD:** "This isn't a tweak. This isn't an update. This is a complete rewrite." (triple-clarification)
**GOOD:** "This is a complete rewrite." (one statement, move on)

### Topic Coverage — Depth Over Breadth
Cover 1-2 topics maximum per video. Go deep, not wide. Each topic should get 2-3 minutes of coverage minimum. A single topic explored thoroughly with context, history, skepticism, and prediction is worth more than 4 topics skimmed.

### Multiple Scenes Per Topic
Each topic/info segment MUST have 8-15 visual scenes. One frame per topic looks like a slideshow. Each narration chunk gets its own visual — vary between text_bold, fullscreen_image, meme_fullscreen, image_collage, etc.

### Meme Content
Include 2-4 meme moments per video. These should be:
- Indirectly related to the topic (like Fireship showing "will it blend" when something gets destroyed)
- Smooth and funny — NOT forced, NOT boomer humor
- Culturally relevant internet humor that the target audience (devs, tech people) would get
- Each meme needs a specific 5+ word image search query (e.g., "will it blend tom dickson blendtec meme")

## 3. CONTENT & ANALYSIS RULES

### Originality Requirements
Every video script MUST include:
- [ ] At least 1 clear opinion/hot take the creator stands behind
- [ ] At least 1 prediction about what happens next
- [ ] At least 1 moment of acknowledged uncertainty ("we don't know yet", "this could go either way")
- [ ] At least 1 comparison to a previous event, competitor, or trend
- [ ] At least 1 specific number, date, or data point (not vague "significant" claims)
- [ ] Context that a casual viewer wouldn't know (backstory, failed attempts, industry dynamics)

### What NEVER to Do
- Copy press release language — always rewrite in your own words
- Treat all information as equally important — emphasize what matters, skip what doesn't
- Present both sides equally on everything — sometimes one side is clearly right, say so
- Use weasel words to avoid taking a position ("some might say", "it could be argued")
- State obvious things ("AI is growing fast") — skip to the non-obvious insight

### Skepticism Checklist
For every claim in the source material, ask:
1. Who benefits from this being true?
2. What's the track record of this company/person making similar claims?
3. What's the counter-argument?
4. What would need to be true for this to actually work?

Include at least one skepticism moment per video. Viewers trust creators who don't hype everything.

### Source Attribution
- Cite sources naturally: "according to The Verge", "Bloomberg is reporting that"
- Don't over-cite — once per major claim is enough
- If the source is the company itself, flag it: "now, this is coming from OpenAI directly, so take the benchmarks with a grain of salt"

## 4. TTS & VOICE RULES

### Cartesia Sonic TTS (Primary)
- Engine: Cartesia Sonic API (cloud, fast, high quality)
- Voice ID: `86e30c1d-714b-4074-a1f2-1cb6b552fb49`
- Model: `sonic`
- Sample rate: 44100Hz
- **Continuous audio**: Full narration is sent as ONE TTS call (not per-scene). This produces fluid, natural speech without choppy seams.

### Kokoro TTS Fallback (if Cartesia unavailable)
- Engine: `kokoro-onnx` (local, free, CPU-compatible)
- Voice: `am_adam` (male, American — matches Fireship tone)
- Speed: `1.15` (fast-paced like Fireship's Jeff Delaney)
- Model: `assets/models/kokoro-v1.0.onnx` + `voices-v1.0.bin`

### Making TTS Sound Human
- Insert `...` in the script where a human would naturally pause (before reveals, after questions, between topic shifts)
- Break long sentences into shorter ones — TTS handles short sentences better
- Use contractions always: "it's", "they're", "won't", "can't", "doesn't" — never "it is", "they are", "will not"
- Write numbers as words for TTS: "forty percent" not "40%" (but show 40% on screen)
- Spell out acronyms on first use if TTS mispronounces them
- Never have a sentence longer than 25 words — break it up

### Audio Architecture — Continuous, Not Stitched
- Audio is ONE continuous file generated from `full_narration` — NOT per-scene WAVs stitched together
- Visual scene changes happen at calculated timestamps while audio flows uninterrupted
- This prevents choppy seams between scenes and produces natural, fluid speech
- Use `assemble_video_continuous()` in video assembly — single AudioFileClip + timed ImageClips

### Narration Rhythm
- Vary sentence length deliberately: short. Medium length here. Then a longer one that builds on the previous two and adds the context you need.
- Use sentence fragments for impact: "Gone. Just like that."
- Parenthetical asides add personality: "and this is the part that gets interesting"
- Direct address: "you" and "your" — talk TO the viewer, not AT them

## 5. VISUAL RULES (Fireship Style)

### Frame Composition (1920x1080)
- Background: **pure black (#000000)** — flat, no gradient, exactly like Fireship
- Primary font: Bangers (titles, big text) — `assets/fonts/Bangers-Regular.ttf` — chunky, heavy display font matching Fireship thumbnail style
- Secondary font: Roboto Bold (body text) — `assets/fonts/Roboto-Bold.ttf`
- Text color: cream white (#F5F5DC) with drop shadow for readability
- **Red accent text**: Words wrapped in `*asterisks*` in `main_text` render in red (#FF3333) with thick dark stroke — for emphasis on key words (Fireship thumbnail style)

### Frame Types (Fireship-inspired)
- **text_bold**: Pure black bg, one LARGE bold white text centered (120px+). For emphasis moments: "I HAVE A QUESTION...", "BUT HERE'S THE THING"
- **image_with_text**: Black bg, real web image on right, bold text on left
- **article_screenshot**: Black bg, web image/screenshot centered with border
- **image_grid**: Black bg, 2x2 grid of real images with bold labels
- **fullscreen_image**: Image fills ~90% of frame with optional text overlay
- **meme_fullscreen**: Meme image fills frame — for humor beats. No photo filter on search. Smooth/funny memes related to topic
- **image_collage**: 2-5 images in organic asymmetric layout with labels. Not a strict grid — one hero image with smaller supporting images

### When to Use Each Frame Type
- **text_bold**: Transitions, emphasis, rhetorical questions, topic headers, punchlines
- **fullscreen_image**: Showcasing a product, person, or concept being discussed
- **meme_fullscreen**: After a punchline, during a comparison to something absurd, humor beats
- **image_with_text**: When showing something while explaining it (image = visual, text = key point)
- **image_collage**: Comparing multiple things, showing a landscape of competitors/options
- **image_grid**: Strict 4-item comparisons (use image_collage for 2-3 or 5+ items)
- **article_screenshot**: Showing a news article, tweet, or source being referenced

### No Subtitles
Do NOT render word-level subtitle overlays. Fireship doesn't use them. The visuals speak for themselves.

### Image Search Rules — CRITICAL
- NEVER search generic single words — they return wrong results
- "Runway" → finds fashion models. Search "Runway AI video generator tool" instead
- "Pika" → finds the animal. Search "Pika AI video generator tool" instead
- Always add domain context: company name + "AI" + product type + "logo" or "tool"
- Use `image_search_queries` list for per-item specific queries in grid frames
- If image download fails, fall back to text_only frame

### What NOT to Do Visually
- No white/cream backgrounds — always pure black
- No gradients on backgrounds — flat black only
- No Ken Burns effect
- No identical layouts in consecutive scenes
- No walls of text — max 8 words on text_only frames
- No stock illustrations or Pillow-drawn shapes — use real web images

### Image QA Checklist (MANDATORY after frame building)
After all frames are built, the team-lead agent MUST review every image-based frame (not text_bold) one by one before video assembly:

1. **Read each frame PNG** and check for:
   - Watermarks (Alamy, Shutterstock, Getty, Vecteezy, Pokde, etc.)
   - White backgrounds (product pages, marketing screenshots)
   - AI-generated images (uncanny faces, holographic elements)
   - Irrelevant content (wrong topic, wrong product, unrelated)
   - Low quality (blurry, pixelated, too small)
   - 2x2 grid layouts (always use side-by-side instead)

2. **Flag bad frames** with the issue type

3. **Fix flagged frames** by:
   - Updating the `image_search_query` in script.json to a more specific query
   - Clearing the cached image file
   - Rebuilding only the flagged frame
   - Re-checking the rebuilt frame

4. **Only proceed to video assembly** when ALL frames pass QA

This step prevents watermarked, irrelevant, or AI-generated images from appearing in the final video.

## 6. YOUTUBE ALGORITHM OPTIMIZATION

### Retention Engineering
- Pattern interrupt every 60-90 seconds: new visual type, tone shift, question to viewer
- Front-load value: the most interesting insight should be in the first 30 seconds
- Create "open loops": mention something coming later ("and wait until you hear what happened next")
- End segments with micro-cliffhangers before transitioning

### Metadata (for when upload is automated)
- Title: max 60 chars, include the specific news item, no clickbait that doesn't deliver
- Description: first 2 lines are the hook (visible before "show more"), include timestamps
- Tags: specific tool/company names + broader category terms

### What the Algorithm Rewards
- High average view duration (most important metric)
- Click-through rate on impressions
- Comments with substance (driven by ending with a real question/opinion)
- Session time (viewer watches another video after yours)

### What Gets You Suppressed
- Viewers clicking away in first 10 seconds (bad hook or misleading title)
- Low comment engagement (signals content isn't worth discussing)
- Repetitive content structure (YouTube detects sameness across videos)
- Viewer surveys marking content as "AI slop" (YouTube actively polls for this since 2026)

## 7. PROJECT TECHNICAL DETAILS

### Directory Structure
```
youtube_auto/
  CLAUDE.md              # This file — project guidelines
  main.py                # Pipeline orchestrator (loads script, runs TTS/frames/assembly)
  news_fetcher.py        # Google Trends/News RSS → top AI/tech story
  script_writer.py       # Script validator + loader (reads output/script.json)
  tts_engine.py          # Script → Cartesia Sonic TTS audio (Kokoro fallback)
  scene_builder.py       # Script → Pillow visual frames (7 frame types)
  video_assembler.py     # Frames + audio → final MP4 (no subtitles)
  requirements.txt       # Python dependencies
  assets/
    fonts/               # Montserrat-Bold.ttf, Roboto-Bold.ttf
    models/              # Kokoro TTS model + voices (fallback)
  output/
    script.json          # Generated by Claude Code subagent
    topic.json           # Trending topic info
    audio/               # Per-scene WAV files
    frames/              # Per-scene PNG frames
    images/              # Cached downloaded images
    video.mp4            # Final assembled video
```

### Script JSON Schema
The script is generated by a Claude Code Sonnet 4.6 subagent and written to `output/script.json`:
```json
{
    "title": "Video Title Here",
    "full_narration": "The COMPLETE narration as one continuous flowing text. This is what TTS reads — it MUST be one cohesive piece, not per-scene fragments joined. Write it like a real script read top-to-bottom.",
    "scenes": [
        {
            "scene_id": 1,
            "narration": "The portion of full_narration that maps to this visual scene (for timestamp calculation).",
            "visual_type": "text_bold|fullscreen_image|meme_fullscreen|image_with_text|image_collage|image_grid|article_screenshot",
            "main_text": "ON-SCREEN TEXT (use *asterisks* for red accent words)",
            "image_search_query": "specific 5+ word search query",
            "image_search_queries": ["query1", "query2"],
            "image_labels": ["LABEL1", "LABEL2"]
        }
    ]
}
```

**CRITICAL**: `full_narration` must be written as ONE continuous piece — not scene narrations concatenated. The per-scene `narration` fields are used ONLY for mapping visual timestamps to the audio. The TTS engine reads `full_narration` in a single call for fluid, natural speech.

### Dependencies
- `moviepy` — video assembly
- `Pillow` — image/frame generation
- `feedparser` — RSS parsing
- `requests` — HTTP requests, Cartesia API
- `kokoro-onnx` — fallback TTS engine
- `soundfile` — audio file I/O
- `numpy` — audio processing

### Running
The pipeline runs via Claude Code agent teams:
1. Team lead fetches trending topic → `output/topic.json`
2. `script-writer` agent generates script → `output/script.json`
3. `audio-producer` and `visual-director` agents run in parallel
4. `assembler` agent combines into `output/video.mp4`

For manual/debug mode: `python main.py` (requires `output/script.json` to exist)

## 8. QUALITY CHECKLIST (Run Before Every Video)

Before exporting any video, verify:

### Script Quality
- [ ] No banned phrases from the block list
- [ ] Hook is in the first sentence — no preamble
- [ ] At least 1 opinion/hot take
- [ ] At least 1 prediction
- [ ] At least 1 uncertainty acknowledgment
- [ ] At least 1 historical comparison or context
- [ ] At least 1 specific data point
- [ ] No sentence longer than 25 words
- [ ] Contractions used throughout (it's, not it is)
- [ ] Script reads conversationally when spoken aloud

### Visual Quality
- [ ] No two consecutive scenes use the same frame type
- [ ] Max 30 words visible on any single frame
- [ ] Color palette is consistent across all frames
- [ ] Text is readable (contrast ratio, font size)
- [ ] No stock photos or generic clip art

### Audio Quality
- [ ] Pauses exist at natural break points
- [ ] No robotic run-on sentences
- [ ] TTS doesn't mispronounce key terms

### Retention Quality
- [ ] Something changes every 60-90 seconds (visual, tone, topic angle)
- [ ] Open loop or teaser in first 30 seconds
- [ ] Ending has a real opinion that could spark discussion
- [ ] No generic outro ("thanks for watching", "like and subscribe")
